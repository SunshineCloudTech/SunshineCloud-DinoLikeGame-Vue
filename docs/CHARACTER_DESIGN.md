# 🏃‍♂️ 小人跑酷游戏 - 角色设计文档

## 🎨 角色设计

### 小人外观特征
- **头部**: 圆形粉色头部，配有可爱的微笑表情
- **头发**: 棕色头发，简单的像素风格
- **眼睛**: 大眼睛，会根据夜晚模式调整颜色
- **服装**: 蓝色上衣，深色裤子，棕色鞋子
- **皮肤**: 粉色调，温暖友好

### 🎯 动画状态

#### 1. 跑步状态 (RUNNING)
- **手臂动画**: 左右手臂交替摆动，模拟真实跑步
- **腿部动画**: 左右腿交替迈步，有明显的前后差异
- **特效**: 额头冒汗效果，体现运动的真实感
- **频率**: 120ms切换腿部动画，150ms切换手臂动画

#### 2. 跳跃状态 (JUMPING)
- **姿势**: 手臂自然下垂，腿部并拢
- **特效**: 身体周围出现绿色光环效果
- **颜色变化**: 整体变成绿色调，突出跳跃状态

#### 3. 蹲下状态 (DUCKING)
- **姿势**: 身体压低，手臂放在膝盖上
- **头部**: 相对低矮，适应蹲姿
- **颜色变化**: 整体变成黄色调
- **碰撞箱**: 自动调整为更低的碰撞检测

#### 4. 碰撞状态 (CRASHED)
- **颜色变化**: 整体变红，表示受伤状态
- **表情**: 保持基本形态但颜色变化明显

### 🌃 夜晚模式适配
- **角色颜色**: 蓝色调整为更亮的蓝色 (#6fa8dc)
- **皮肤颜色**: 调整为适合夜晚的粉色调
- **眼睛颜色**: 白色，在黑暗中更突出
- **特效颜色**: 所有特效都调整为夜晚友好的颜色

## 🎮 操作控制

### 键盘操作
- **空格键** / **↑方向键**: 跳跃
- **↓方向键**: 蹲下 (按住持续蹲下，松开恢复)

### 触摸操作
- **点击屏幕**: 跳跃 (移动设备)

## 🚧 障碍物设计

### 垃圾桶 (小障碍物)
- **颜色**: 橙色主体，红色盖子
- **特征**: 带手柄和垃圾分类标识
- **高度**: 需要跳跃越过

### 交通锥 (大障碍物)  
- **颜色**: 红色主体，白色反光条
- **形状**: 经典锥形设计
- **高度**: 较高，需要跳跃越过

### 飞行无人机 (飞行障碍物)
- **颜色**: 蓝色机身，绿色机头
- **动画**: 螺旋桨旋转，LED灯闪烁
- **飞行高度**: 随机，需要跳跃或蹲下躲避

## 🎨 视觉特效

### 跳跃特效
- **光环**: 绿色虚线圆圈，围绕角色
- **半径**: 25像素
- **样式**: 虚线效果 (5px间隔)

### 跑步特效
- **汗水**: 蓝色小圆点
- **位置**: 头部右侧随机位置
- **频率**: 200ms间隔闪现

### 障碍物特效
- **无人机螺旋桨**: 100ms旋转一次，4个方向
- **LED灯**: 红绿灯交替闪烁，300ms频率

## 🎯 游戏体验优化

### 角色反馈
1. **状态色彩**: 不同状态有明显的颜色变化
2. **动画流畅**: 所有动画都有合适的帧率和节奏
3. **特效增强**: 适当的视觉特效增加游戏趣味性

### 障碍物多样性
1. **地面障碍**: 垃圾桶、交通锥等静态障碍
2. **空中障碍**: 无人机等动态飞行物
3. **视觉区分**: 每种障碍物都有独特的外观和动画

### 交互体验
1. **响应及时**: 按键响应迅速准确
2. **操作直观**: 简单的跳跃和蹲下操作
3. **反馈清晰**: 状态变化有明显的视觉反馈

## 🚀 技术实现

### 渲染技术
- **Canvas 2D**: 像素完美的图形渲染
- **requestAnimationFrame**: 流畅的动画循环
- **状态管理**: Vue 3 响应式状态管理

### 性能优化
- **最小重绘**: 只更新必要的画布区域
- **动画缓存**: 复用计算结果
- **内存管理**: 及时清理不需要的对象

这个设计让游戏从单调的恐龙变成了一个生动有趣的小人跑酷游戏，增加了更多的视觉魅力和游戏乐趣！

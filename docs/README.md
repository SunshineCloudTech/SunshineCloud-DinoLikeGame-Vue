## 🎮 项目概述

这是一个基于 Vue 3 + TypeScript + Vite 构建的跑酷游戏，重新实现了经典的 Chrome 离线小恐龙游戏，并使用了自定义的像素艺术风格角色。

## 🛠️ 技术栈

- **前端框架**: Vue 3 (Composition API)
- **开发语言**: TypeScript
- **构建工具**: Vite
- **渲染技术**: HTML5 Canvas 2D
- **样式**: CSS3 (支持响应式设计)
